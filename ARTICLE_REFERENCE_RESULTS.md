# SoftwareX reference run - PortGuard-AIS 1.0.0

This file records the deterministic reference values generated by
`examples/softwarex_article_run.py` for the SoftwareX reproducibility suite.
These values describe controlled synthetic scenarios and must not be interpreted as real-world
navigation-system accuracy or collision-prevention effectiveness.

- Scenario count: 3
- Steps per scenario: 12
- Sampling interval: 30 s
- AIS input rows: 72
- Unique vessels: 6
